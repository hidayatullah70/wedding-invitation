# PROMPT EXECUTION — Initial Project Setup

Salin prompt ini ke Antigravity IDE setelah seluruh file SOT dan `AGENTS.md` berada di root project.

---

Bertindak sebagai Senior Frontend Developer, UI/UX Designer, dan implementer yang mengikuti kontrak `AGENTS.md`.

## TUGAS
Siapkan fondasi awal website undangan pernikahan digital menggunakan:
- HTML semantik
- React
- Vite
- Tailwind CSS

Gunakan dokumen berikut sebagai satu-satunya acuan:
`PRD.md`, `USER-FLOW.md`, `UI-GUIDELINE.md`, `API-SPEC.md`, `IMPLEMENTATION-PLAN.md`, dan `AGENTS.md`.

## LANGKAH WAJIB
1. Audit folder project saat ini. Jangan menghapus atau menimpa file yang tidak terkait.
2. Baca seluruh dokumen SOT sebelum coding.
3. Periksa versi Node.js/npm dan konfigurasi project.
4. Jika project belum ada, inisialisasi React + Vite dan konfigurasi Tailwind CSS dengan setup resmi yang kompatibel. Jangan mencampur instruksi Tailwind v3 dan v4.
5. Buat struktur folder minimal yang disarankan dalam `IMPLEMENTATION-PLAN.md`.
6. Implementasikan fondasi visual: design tokens, typography, global layout, responsive container, button, dan section heading.
7. Buat satu halaman undangan awal dengan section placeholder terstruktur sesuai urutan di `PRD.md`. Gunakan data placeholder yang jelas dan mudah diganti dari satu file konfigurasi.
8. Jangan membuat backend, database, dashboard admin, login, payment gateway, atau fitur di luar PRD.
9. RSVP dan guestbook pada tahap fondasi hanya boleh memakai demo adapter yang diberi label jelas bila API belum tersedia. Jangan menyatakan data tersimpan permanen.
10. Pastikan audio tidak autoplay dan semua interaksi memiliki state yang jelas.
11. Jalankan dev/build/lint/test yang tersedia. Perbaiki error yang disebabkan implementasi.
12. Jangan berhenti setelah membuat file konfigurasi; tampilkan halaman yang benar-benar dapat dijalankan.

## ARAH DESAIN
Buat visual romantis-modern Gen Z: blush pink, soft blue, ivory, rose, champagne; kombinasi serif elegan dan sans-serif modern; whitespace luas; foto/ornamen tidak berlebihan; mobile-first. Hindari tampilan template Bootstrap generik.

## BATASAN
- Jangan mengubah isi dokumen SOT tanpa instruksi.
- Jangan menambah dokumen SOT lain.
- Jangan menyalin aset/source code/data pribadi dari repository Dino Wedding.
- Jangan mengarang identitas pasangan, tanggal, venue, rekening, foto, atau URL peta.
- Jangan menambahkan dependency besar tanpa kebutuhan.
- Bila ada keputusan yang tidak dapat ditentukan dari SOT, gunakan placeholder/configuration dan laporkan, jangan mengarang.

## OUTPUT WAJIB
Berikan:
1. Ringkasan pekerjaan.
2. Struktur folder akhir.
3. Daftar file yang dibuat/diubah.
4. Cara menjalankan project.
5. Hasil build/lint/test.
6. Daftar placeholder dan data yang masih harus disediakan pemilik undangan.
7. Fitur yang masih demo atau menunggu API.

Mulai dari audit dan lanjutkan sesuai urutan. Jangan mengerjakan di luar konsep dan scope SOT.
